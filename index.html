LandinPage

An AI agent that builds and edits code from natural language, running entirely in the browser.

I built an autonomous coding agent from scratch in Python, a tool-calling loop that reads files, writes files, and runs shell commands based on natural language instructions, then packaged it behind a FastAPI backend and a React frontend. The hardest problem was bridging a server-side agent to a client-side runtime: the agent’s file and command operations stream as events to the frontend, which mounts them into a live WebContainer instance in the user’s browser, so each user gets an isolated build environment with no server-side sandboxing needed. The app also includes a guided onboarding flow that turns structured design decisions (typography, color, layout, motion) into a JSON spec the agent builds from. Containerized with Docker and deployed to production, currently serving 27 users.

Live at landinpage.infinityrecursion.net

Python · FastAPI · React · Docker · WebContainer
